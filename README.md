# موقع سديم لأنظمة الأمن والسلامة

موقع تعريفي بلغة عربية (RTL) لشركة سديم للأمن والسلامة (سديم لأنظمة الأمن والسلامة) في المملكة العربية السعودية: توريد وتركيب وصيانة أنظمة مكافحة الحريق والإنذار المبكر، معدات السلامة، مخططات السلامة، والشهادات والتقارير الفنية.

الموقع ثابت بالكامل (HTML + CSS + JavaScript) بلا أي خطوة بناء، ويمكن نقله إلى أي استضافة ثابتة كما هو. المحتوى كله مستخرج من الملف التعريفي للشركة.

## الروابط

| الاستضافة | الرابط |
|---|---|
| GitHub Pages | https://mostafa-gamal-png.github.io/sadeem/ |
| Vercel | يُنشر تلقائيًا من الفرع `main` ضمن مشروع Vercel المرتبط بالمستودع |

صفحة الحسابات البنكية للشركة متاحة على المسار `bank.html` ومربوطة من تذييل الموقع.

## التشغيل محليًا

لا يحتاج الموقع إلى أي تثبيت. افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا محليًا من داخل المجلد:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## تعديل المحتوى

كل المحتوى المتغيّر في ملف واحد: `js/data.js`. الأقسام التي تكون مصفوفتها فارغة تُخفى تلقائيًا من الصفحة ومن القائمة، وأي حقل تواصل فارغ يُخفى من مكانه.

| ما تريد تعديله | أين |
|---|---|
| اسم الشركة ووصفها ورابط الموقع | `company` |
| الهاتف، الجوال، الواتساب، البريد، العنوان، الخريطة | `contact` |
| نصوص رسائل الواتساب لكل نوع طلب | `whatsappMessages` (الكلمة `{service}` أو `{product}` تُستبدل تلقائيًا) |
| صورة الشاشة الأولى وتعليقها ومراحل العمل | `hero` |
| شعارات "من عملائنا" | `clientLogos` |
| نص "تعرف على سديم" وصورته | `about` |
| الخدمات الست | `services` (`enabled: false` تخفي خدمة دون حذفها) |
| مجموعات المنتجات | `products.items` |
| المشروعات المصوّرة | `projects` |
| قوائم المواقع حسب القطاع | `sectors.groups` |
| صور العملاء الـ14 وأسماؤها | `clients` |
| شركاء النجاح (إن وُجدوا) | `partners` |
| التراخيص والوثائق | `documents` |

### الملفات القابلة للتحميل

- **الملف التعريفي:** ضع الـ PDF في `assets/docs/` واكتب مساره في `company.profileFile`. يظهر زر "تحميل بروفايل الشركة" تلقائيًا في الشاشة الأولى وقسم التواصل والتذييل.
- **كتالوج المنتجات:** ضع الـ PDF في `assets/docs/` واكتب مساره في `company.catalogFile`. يظهر زر التحميل في قسم المنتجات والتذييل.

### الوثائق وحالة الصلاحية

كل وثيقة لها `issuer` (الجهة)، و`details` (أزواج عنوان/قيمة تُعرض كما هي)، و`expires` بتاريخ ميلادي بصيغة `YYYY-MM-DD` لحساب شارة "سارية / منتهية الصلاحية" تلقائيًا مقارنة بتاريخ اليوم. اترك `expires` فارغًا لوثيقة بلا تاريخ انتهاء (كالسجل التجاري).

ترخيص الهيئة العليا للأمن الصناعي تاريخه هجري (23 / 03 / 1449 هـ)؛ القيمة الميلادية المسجلة في `expires` تقريبية لحساب الحالة فقط، والتاريخ الهجري هو المعروض.

### إضافة صور جديدة (عملاء أو مشروعات)

1. شغّل أداة الضغط (تحتاج Python ومكتبة Pillow: `pip install pillow`):

```bash
python3 tools/optimize-images.py clients  "مسار/صورة1.jpg" "مسار/صورة2.jpg"
python3 tools/optimize-images.py projects "مسار/صورة.jpg"
python3 tools/optimize-images.py hero     "مسار/صورة-الشاشة-الأولى.jpg"
```

2. الأداة تحفظ النسخة الكبيرة (حتى 1600 بكسل) والمصغّرة (حتى 640 بكسل) داخل `assets/img/<المجموعة>/` دون قص، وتطبع مقطعًا جاهزًا للصق في `js/data.js`.
3. أكمل اسم المنشأة من مصدر موثق فقط. لا تنسب صورة إلى منشأة غير معروفة.

ملاحظة: صور العملاء الحالية مستخرجة من الملف التعريفي بدقة 640 بكسل. إن توفرت الصور الأصلية بدقة أعلى، مرّرها بالأداة نفسها بنفس الأسماء لتحل محل الحالية.

## الرفع على الاستضافة

### GitHub Pages (الوضع الحالي)

- أي دفعة إلى الفرع `main` تشغّل `.github/workflows/publish-pages.yml` الذي ينسخ الملفات إلى الفرع `gh-pages`، ومنه يُقدَّم الموقع خلال دقيقة تقريبًا.
- لا تعدّل الفرع `gh-pages` يدويًا؛ يُعاد إنشاؤه مع كل نشر.
- لربط نطاق خاص: Settings → Pages → Custom domain في GitHub، ثم حدّث `company.siteUrl` في `js/data.js` وروابط `og:url` و`og:image` و`canonical` في `index.html`.

### Vercel

المستودع مرتبط بمشروع على Vercel يُنشر تلقائيًا من `main`، وينشئ معاينة لكل فرع آخر.

### أي استضافة ثابتة أخرى

ارفع محتويات المجلد كاملًا (ما عدا `.git` و`.github` و`tools`) إلى جذر الاستضافة. كل المسارات نسبية فلا يلزم أي تعديل.

## قائمة التحقق قبل النشر

- [ ] الملف التعريفي PDF في `assets/docs/` ومساره في `company.profileFile`.
- [ ] كتالوج المنتجات PDF في `assets/docs/` ومساره في `company.catalogFile`.
- [ ] مراجعة بيانات التواصل في `contact` (الهاتف، الجوال، الواتساب، البريد، العنوان).
- [ ] تحديث `siteUrl` و`og:url` و`canonical` عند اعتماد النطاق النهائي.
